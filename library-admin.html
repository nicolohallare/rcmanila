Heritage Library workshop

This page reads the Club’s private archive, makes web-sized copies, removes members’ home addresses, and saves the result to the public library. Keep this tab open while a job runs; you can leave it running overnight. A job can be stopped and started again at any time; finished items are skipped.

Trophy room: plaques, trophies and medals

Step 1 (Start) makes a web copy of each photographed plaque or trophy. Step 2 (Polish photos and read labels) cuts each object out of its background, sets it on the gallery backdrop, and reads the text printed on it for a clean title, the giver and the year. It takes about 15 seconds an item; the original photos are kept. Then check a few and click Publish all.

Bound Balita volumes, 1948–2009

Each volume is read page by page: a web image of every page, the page text (read by machine where the scan has none), and the issues found inside. Pages that print home addresses have those lines blanked; member directories are withheld. Volumes with the same issues are grouped; the best copy is ticked.

A volume takes about 5 to 20 minutes. The whole shelf can take a few nights. Use a computer that stays on, with a good connection.
